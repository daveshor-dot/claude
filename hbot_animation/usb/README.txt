HYPERVAN CONTROL PANEL LOOP - TV USB SETUP
==========================================

WHAT IS HERE
  HYPERVAN_4K.mp4   For 4K (Ultra HD) TVs. 4 minutes of the 30-second
                    sequence, repeated seamlessly.
  HYPERVAN_HD.mp4   For 1080p / HD TVs, or any TV that won't play the 4K
                    file. 14 minutes, repeated seamlessly.

Put ONLY ONE of the two videos on the USB drive. With both on it, the TV
may try to play the one it can't handle.


1. PREPARE THE USB DRIVE (one time)
   The drive must be formatted as exFAT (preferred) or FAT32. Most TVs
   read both. Formatting erases the drive.

   Windows:  File Explorer > right-click the USB drive > Format...
             File system: exFAT > Start.
   Mac:      Disk Utility > select the USB drive > Erase.
             Format: ExFAT, Scheme: Master Boot Record > Erase.

2. COPY THE VIDEO
   Drag HYPERVAN_4K.mp4 (or HYPERVAN_HD.mp4) onto the drive. Put it
   directly on the drive, not inside a folder. Eject the drive safely
   before you unplug it.

3. PLAY IT ON THE TV
   Plug the drive into the TV's USB port and switch to the USB input.
   Open the video once, then turn on the TV player's repeat option
   (usually in the player's Options or Settings menu while the video is
   playing):
     Samsung   Options > Repeat > Repeat One (or Repeat All)
     LG        Settings (gear) in the player > Repeat > Repeat One
     Sony      Options > Repeat > One / All
     TCL/Roku  Roku Media Player > * button > Repeat
     Hisense   Options (or ...) > Repeat mode > Single
   Many TVs remember this setting. If yours has no repeat option, the
   video still runs for 4 minutes (4K) or 14 minutes (HD) before it
   ends.

   NOTE: A TV can't run a program from a USB drive. It can only play
   media files with its built-in player, so the only settings the video
   can use are the player's own. Many TVs open the USB file browser when
   you switch to the USB input. Some start playing automatically, and
   some resume the last file. That depends on the TV model.

   For a fully hands-off display, some TVs have a commercial or "hotel"
   mode with USB auto-play on power-up (LG, Samsung and Sony
   professional displays have this). A small media player stick, or
   a "digital signage" media player, also plays a USB video on a loop
   as soon as it's turned on.

4. IF IT WON'T PLAY
   - Try HYPERVAN_HD.mp4. Some older or budget 4K TVs can't decode
     this 4K file from USB.
   - Check that the drive is exFAT or FAT32 (not NTFS or Mac OS
     Extended).
   - Try the TV's other USB port (on some TVs only one port plays
     video).

The picture has no sound. The file includes a silent audio track because
some TVs won't play a video that has none.
